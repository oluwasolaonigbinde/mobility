# Vendored fonts

- **Clash Display** and **Satoshi** — Indian Type Foundry, distributed via
  [Fontshare](https://www.fontshare.com) under the ITF Free Font License
  (free for personal and commercial use; self-hosting permitted).
- **IBM Plex Mono** — loaded via `next/font/google` (OFL), not vendored here.

If the client later licenses a different brand typeface, swap these in
`src/lib/fonts.ts` — nothing else references the files directly.
