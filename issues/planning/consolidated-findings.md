# Consolidated first-pass audit findings

## Status and interpretation

This file normalizes 115 candidate findings from the 14 first-pass audit
artifacts. It is not a verification of the current repository, a remediation
decision, or a work order. Every candidate below is **UNVERIFIED**. “Source
severity” and “confidence” are the source authors' labels, not adopted
classifications.

All sources audited commit `637841d95493bcc24334356da42097fa53a5d16f`.
All 14 source artifacts are complete. **C** in the source-snapshot column means
that every artifact supporting that candidate is a complete `COLLECTED`
artifact.

“Overlap” records merged or related source claims. It does not assert that the
underlying behavior is the same at the current repository state. Verification
targets are path and test names suggested by the sources; no target was opened
or executed during normalization.

## Corpus limitations

- GPT-01 through GPT-08 are complete owner-supplied responses. The 14-artifact
  manifest therefore consists entirely of complete sources.
- Every source reviewed the same historical snapshot, not the current working
  tree. No normalized claim has been checked against current source.
- Source authors used different execution environments. In particular, some
  report no executable checkout while others report focused probes or test
  counts. Those statements are retained as source-specific evidence and are
  not reconciled into a new truth claim here.
- Positive controls, rejected suspicions, external inputs, and owner questions
  were read for context but were not converted into defect candidates unless
  they expressed a concrete gap (for example ONB-009, REP-007, REL-008).
- No remediation priority or implementation order is created by this file.
