## Change-control rule

An integrated row changes only with repository evidence and the normal package
authority. An external/live row changes only when its registered gate and
required live evidence are approved. A post-MVP idea becomes work only through
a separately authorized future decision and queue entry. This document neither
reopens completed packages nor moves unfinished pilot obligations into the
post-MVP lane.
